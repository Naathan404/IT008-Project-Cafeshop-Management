# IT008-Project-Cafeshop-Management

## APP DESCRIPTION

# Những đối tượng cần quản lý
- Nhân viên
- Menu
- Order
- Kho
- Bàn
# Chức năng chính cơ bản
- Đăng nhập (đăng nhập, lấy lại mật khẩu qua email) và phân quyền (quản lý / nhân viên).
- Hiển thị danh sách bàn (bàn số mấy, trạng thái <trống, đang sử dụng>,...)
- Menu (Thêm, cập nhật, xóa món; chia món theo danh mục; mỗi món có 3 size)
- Order (tạo đơn, thêm món - sửa - xóa món trên đơn, chọn hình thức dùng (tại chỗ - mang đi), chọn hình thức thanh toán (tiền tươi - chuyển khoản), chốt đơn, in hóa đơn).
- Kho (các loại hàng hóa (trạng thái<còn, hết, đang nhập hàng>)
- Thống kê doanh thu (thống kê theo từng ca, theo cả ngày, thống kê những món bán chạy nhất, khung giờ bán chạy)
